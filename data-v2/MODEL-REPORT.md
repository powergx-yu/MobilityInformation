# 西武池袋線 線路モデル v1 — 作成レポート

対象: 西武池袋線 上り（池袋方面＋有楽町線/副都心線直通）、平日ダイヤ（2025年3月15日改正）。
成果物: `seibu-ikebukuro-model.json`（駅一覧・種別別停車パターン・停車駅間の発→発分数）。

## 結論（先に正直な数字）

- 保谷駅での検証（所沢発をアンカーにモデルで再生成）: 追跡できた15チェーン中、**完全一致 8件（53%）、±1分以内 14件（93%）**、最大偏差 −2分が1件。
- 目標だった「99%完全一致」には**届いていない**。理由はモデルの誤りではなく、実ダイヤ自体が同一区間に2種類の標定時分を持つため（下記「二峰性」参照）。単一値モデルでは原理的に再現できない部分がある。
- 保谷以外（石神井公園）でのスポットチェック: 急行・Fライナー計5件中、完全一致4件、+1分1件。

## 方法

1. 駅探（ekitan.com）の各駅時刻表ページ（平日・上り）を全駅分取得。URL形式:
   `https://ekitan.com/timetable/railway/line-station/235-{SI番号−1}/d1?dw=0`
   （例: 保谷=235-11、飯能=235-25、池袋=235-0）。駅探のデータは鉄道会社からの購入データで、西武公式標準時刻表と一致することを保谷で照合済み。
   西武有楽町線は別路線ID: `232-0`=小竹向原、`232-1`=新桜台、`232-2`=練馬。
2. 駅探の列車詳細ページはJS描画で本文が取れないため、列車の同定は「種別＋行先＋時刻の連続性」で駅間を手作業で突き合わせた。日中は毎時繰り返しパターン（10–15時）を使い、通勤急行（5本）・通勤準急（1本）・S-TRAIN（2本）は全列車を追跡した。
3. 区間時分は「連続する停車駅の発時刻の差」を複数サンプル取り、中央値/最頻値を採用。
4. 所沢駅の駅探ページは凡例しか返らない不具合があったため、所沢の発時刻は西武鉄道公式「標準時刻表」PDFのテキストで補った:
   `https://seibu.ekitan.com/pdf/20250315/SI17_秋津・池袋・新木場・渋谷・横浜方面_平日.pdf`
5. 池袋到着時刻は駅時刻表に現れないため、終端区間（練馬→池袋など）は下り列車の発→発差（対称性）から求めた。下り実測例: 準急 池袋→練馬 6分、快速 同8分、急行 池袋→石神井公園 9分、各停 池袋→椎名町 3分（いずれも複数サンプル一致）。
6. 支線の練馬→小竹向原は、練馬・新桜台両駅の上り実測差（練馬→新桜台 3分）と、NAVITIMEの区間時刻表（小竹向原→練馬 発→着 4–5分）から推定した:
   `https://www.navitime.co.jp/diagram/depArrTimeList?departure=00003729&arrival=00009060&line=00000729&updown=0`

### クロスチェック（累積合計）

- 準急 保谷→池袋 = **18分** — v1真値ファイル（下り）の固定値18分と一致。
- 各停 保谷→池袋 = **24分** — v1下りファイルの固定値26分とは2分差。ただし26分は当時の推定値で、本モデルの24分は全区間の実測差の積み上げ。モデルの方を採る。
- 小竹向原→保谷（逆算）: 各停18分 / 準急17分。v1推定（20分/16分）と±2分以内で整合。

## 二峰性（検証が100%にならない主因）

同一種別・同一区間に、列車によって異なる標定時分が実在する:

- 準急 東久留米→ひばりヶ丘: {5, 6} 分（毎時2本で交互）。所沢→秋津も {3, 4}。
- 準急 狭山ヶ丘→小手指: {3, 6} 分（小手指での接続待ちの有無）。
- 各停 東久留米→ひばりヶ丘: {3, 5} 分。検証で −2分となった各停10:13所沢発（元町・中華街行）は 3分型のチェーン。
- 各停 狭山ヶ丘→小手指 = 6分は待避（追い越し待ち）込み。純走行は約3分。
- 各停 大泉学園→石神井公園: 実測 {2, 3, 5, 7} 分と幅が大きい（石神井公園での待避）。モデルは中央値3分を採用。

v2アプリ側で精度を上げるなら、「区間時分を時間帯/列車パターン別に2値持つ」拡張が有効（特に準急の東久留米→ひばりヶ丘と各停の東久留米→ひばりヶ丘）。

## 既知のギャップ・不確実性

1. **推定値の区間**（到着時刻が公開時刻表に現れない/始発駅ページに載らない等）:
   - 特急 所沢→池袋 22分（下り実測 約23分から停車時分を引いた推定）
   - 通勤急行 石神井公園→池袋 10分（急行9分＋余裕の仮定）
   - 通勤準急 練馬→池袋 6分（準急と同一視）
   - S-TRAIN 小手指→所沢 5分（小手指発時刻が駅探に表示されず未検証。モデルは所沢アンカーで実用上問題なし）
   - 支線 新桜台→小竹向原 2分（合計時間からの逆算）
2. **仮定で置いた区間**:
   - 快速の所沢以西は急行と同一視。ただし飯能→入間市の合計9分はメトロ直通快速の実測（飯能06:56→入間市07:05）と一致を確認済み。
   - 快速急行の小手指→所沢・所沢→ひばりヶ丘・ひばりヶ丘→石神井公園はFライナー実測と同一視、石神井公園→池袋は急行と同一視。
   - Fライナーの飯能→小手指は快速急行（池袋発着）の朝実測と同一視。
3. **所沢PDFの文字化け**: 07時台の一部が判読不能で、通勤準急の所沢発（07:51）と通勤急行4本目の所沢発（約07:53–55）は前後駅からの推定値。検証表の通勤準急チェーンはこの推定アンカーに依存する。
4. **保谷 各停 10:24（池袋行）** に対応するひばりヶ丘発が駅探リストで綺麗に対応しない例が1件あった（ひばりヶ丘10:24は元町・中華街行）。ひばりヶ丘→保谷=3分自体は多数のクリーンなサンプルで確定しており、モデルには影響しない。
5. **対象外**: 下りモデル、土休日ダイヤ、小竹向原以東の東京メトロ区間（S-TRAINの飯田橋・有楽町・豊洲、Fライナーの副都心線内停車駅）、豊島園支線、狭山線。

## 停車パターンの根拠

各駅の駅探ページに現れる種別フィルタ、pixiv百科事典・noonsiteの停車駅表と相互に照合し、全て一致した。要点のみ:

- 通勤急行は練馬を通過（練馬ページに通急の掲載なし）、ひばりヶ丘も通過し東久留米→保谷が直通。
- 通勤準急は石神井公園を通過し、大泉学園→練馬が直通（10分）。
- 快速は保谷・大泉学園を通過。急行は練馬を通過し所沢以西は全駅停車。
- S-TRAIN（平日上り）は西所沢を通過、所沢・保谷・石神井公園は乗車専用。
- Fライナーは新桜台を通過、練馬に停車。
